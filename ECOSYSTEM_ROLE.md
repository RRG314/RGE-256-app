# Ecosystem Role

**Repository role:** Full browser demo and teaching-facing analysis environment for RGE256

This repository is the most feature-complete browser-facing RGE256 demo. It is meant to make the generator understandable and inspectable without requiring a Python environment.

## Keep Here
- the live demo and installable PWA surface
- visualizations, statistical summaries, and Monte Carlo demonstrations
- export and reporting features intended for interactive use
- release notes and guidance for demo users

## Keep Out
- low-level package development better handled in `rge256`, `numpyrge256`, or `torchrge256`
- the full research-program narrative, which belongs in the main RGE research repo
- unrelated theory notes that are not needed to use the app
