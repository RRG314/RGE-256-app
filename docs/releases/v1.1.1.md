## Overview

This is a documentation and presentation refresh for the full RGE256 browser demo. The goal of the release is to make the app easier to discover, easier to understand, and easier to place inside the wider RGE ecosystem.

## What This Demo Is For

The full demo is the best browser entry point if you want to inspect the generator interactively, run quick statistical checks, explore simple Monte Carlo experiments, and export results without installing Python packages.

## What Changed

- rewrote the repository front page in plainer language
- clarified the difference between the full demo, the lite demo, and the package repositories
- added a simple release-note trail so the repo reads more like a maintained public project
- left the app itself unchanged in this pass

## What Did Not Change

- no new randomness claims
- no new benchmarking claims
- no new browser features
